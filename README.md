# Public Library

**Live Demo**: [Click here to view the live demo](https://hasan042021.github.io/public_library_static/)

## Overview

Public Library is a platform that allows users to manage their reading activities and wallet. Users can borrow books, deposit money into their wallets, and get refunds upon returning books. The platform also includes a review system where only users who have borrowed a book can leave comments.

## Features

### 1. User Account Management

- **Create an Account**: Users can sign up by providing necessary details like name, email, and password.
- **Login**: Users can log in to their account using their email and password.

### 2. Wallet Management

- **Deposit Money**: Users can deposit money into their wallet to use for borrowing books.
- **Borrowing Books**: When a user borrows a book, the cost will be deducted from their wallet.
- **Refunding Money**: When the book is returned, the borrowed amount will be refunded back to the user's wallet.

### 3. Book Collection & Borrowing

- **View Book Collection**: Users can see the full collection of available books in the library.
- **Borrow Books**: Borrowing a book will cost money, which will be deducted from the user's wallet.

### 4. Book Return & Wallet Update

- **Return Books**: Once a book is returned, the money spent on borrowing it will be refunded into the user's wallet.

### 5. Reviews and Comments

- **Comment Section**: Each book has a comment section where users can leave reviews.
- **Review Restrictions**: Only users who have borrowed the book can leave a review. If the user has not borrowed the book, they will not be able to comment.

### 6. Book Filtering

- **Filter Books**: Users can filter books based on categories like Fiction, Non-Fiction, Science, and others.

### 7. User Activity History

- **View Borrowing History**: Users can see a list of all the books they have borrowed, along with their status (whether returned or not).
- **Due Dates**: Users can view the due date for each borrowed book.
